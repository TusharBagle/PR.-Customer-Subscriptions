# 📊 Customer Subscription & Churn Analytics

### Power BI Dashboard for Customer Retention, Subscription & Churn Analysis

This project analyzes **customer subscription behavior, engagement, feedback, and churn patterns** using Power BI. The dashboard was developed to transform raw customer data into meaningful business insights that can help organizations understand **why customers leave, which subscription plans have higher churn, and where retention strategies should be focused**.

## 🛠️ How This Dashboard Was Built

The project was developed using a complete **Business Intelligence workflow**:

**1. Data Preparation**
Raw customer subscription data was prepared and cleaned to ensure the data was suitable for analysis.

**2. Data Modeling**
The required fields were organized into a structured data model to support accurate analysis and interactive reporting.

**3. DAX Calculations**
DAX measures were created to calculate important business metrics such as:

* Total Customers
* Churned Customers
* Churn Rate %
* Active Customers
* Average Feedback Score
* Average Days Since Last Login
* Total Sessions

**4. Data Visualization**
Interactive Power BI visuals were designed to analyze:

* Subscription-wise churn
* Active vs. churned customers
* Customer sessions
* Feedback scores
* Monthly subscription trends
* Customer demographics

**5. Business Analysis**
The final dashboard was analyzed from a business perspective to identify **customer retention opportunities, high-risk subscription segments, and actionable recommendations**.
